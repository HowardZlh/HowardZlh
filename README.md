## Stellar Odyssey: from a planet's surface to the edge of the universe

<a href="https://stellar.guushu.com/en"><img align="right" width="300" src="https://raw.githubusercontent.com/HowardZlh/stellar-odyssey/main/docs/media/zoom-journey-poster.jpg" alt="Stellar Odyssey zooming out from Earth past the Solar System and the Milky Way, rendered in Three.js"></a>

One scroll wheel, four zoom levels: Earth, the Solar System on real Keplerian orbits, the Milky Way, then 43,000+ real galaxies. It's built with React and Three.js, and runs in any WebGL browser with nothing to install.

**[Try it live →](https://stellar.guushu.com/en)** · [Source](https://github.com/HowardZlh/stellar-odyssey) · [60 fps video](https://github.com/HowardZlh/stellar-odyssey/releases/download/v0.1.2/zoom-journey-60fps.mp4)
